个人简介

王焱林，中山大学软件工程学院副教授、博士生导师。聚焦大模型、智能体与可信人工智能，探索具备推理、记忆、工具使用和自主协作能力的新一代智能系统，应用场景为软件智能体、问答、具身智能等。

2010–2014 年就读于浙江大学，获学士学位。2014–2019 年就读于香港大学计算机科学系，师从 Bruno C. d. S. Oliveira 教授，获博士学位。2019–2022 年在微软工作，合作导师为张冬梅和韩石。2022 年 7 月入选中山大学百人计划，加入软件工程学院。

代表性论文

完整目录按年份收录于个人主页的论文列表。下列引用量来自 Google Scholar，统计于 2026-11-25。

软件智能体与仓库级开发

  • SWE Data Construction, Automatically!（FSE 2026）
    SWE-Factory 自动搭建测试环境，验证修复前失败的测试能否在修复后通过，把真实 GitHub issue 转化为软件智能体的训练和评测任务。
  • OmniGIRL: A Multilingual and Multimodal Benchmark for GitHub Issue Resolution（ISSTA 2025）
    OmniGIRL 用四种编程语言的 GitHub issue 评测智能体的修复能力，覆盖需要结合截图理解的问题。
  • MicroAgent: Context-Augmented Multi-agent Framework for Automatic Microservice Decomposition（ASE 2026）　🏅 ACM SIGSOFT Distinguished Paper Award 🏅
    五个智能体结合代码上下文和分析工具识别服务边界，将单体应用拆分为微服务。
  • RLCoder: Reinforcement Learning for Repository-Level Code Completion（ICSE 2025）　被引 143 次
    RLCoder 用强化学习训练检索器，以代码片段对补全的实际帮助为反馈，学习从仓库的其他文件中选择上下文。
  • RepoReasoner: Evaluating Repository-Level Code Reasoning Ability of Long-Context Language Models（FSE 2026）
    RepoReasoner 让模型预测程序输出和函数调用链，检验它能否跨越多个文件追踪代码的执行过程。
  • HumanEvo: An Evolution-Aware Benchmark for More Realistic Evaluation of Repository-Level Code Generation（ICSE 2025）
    HumanEvo 还原开发者编写函数时的仓库版本，衡量后续提交中的信息会让代码生成得分虚高多少。

代码生成的可靠性与效率

  • LLM Hallucinations in Practical Code Generation: Phenomena, Mechanism, and Mitigation（ISSTA 2025）　被引 374 次
    研究归纳了大模型在仓库级代码生成中出现的幻觉类型，并检验检索相关上下文能否减少这些错误。
  • Beyond Functional Correctness: Investigating Coding Style Inconsistencies in Large Language Models（FSE 2025）
    通过对照开发者和大模型编写的代码，研究分析了两者在可读性、简洁性和健壮性上的差异。
  • When to Stop? Towards Efficient Code Generation in LLMs with Excess Token Prevention（ISSTA 2024）　🏅 ACM SIGSOFT Distinguished Paper Award 🏅
    CodeFast 用轻量分类器判断模型是否已写完所需代码，及时停止生成，省去输出多余 token 的推理开销。
  • EffiReasonTrans: RL-Optimized Reasoning for Code Translation（IEEE TSE 2026）
    EffiReasonTrans 先用经过验证的样例训练代码翻译模型，再用强化学习奖励通过测试且推理开销较低的翻译结果。

代码表示、训练与评测

  • UniXcoder: Unified Cross-Modal Pre-training for Code Representation（ACL 2022）　被引 1,511 次
    UniXcoder 联合源代码、注释和抽象语法树进行预训练，让同一个模型支持代码理解与生成。
  • CoCoSoDa: Effective Contrastive Learning for Code Search（ICSE 2023）
    CoCoSoDa 遮盖或替换代码和查询中的词元来构造训练样例，再用对比学习拉近自然语言查询与相关代码的表示。
  • Large Language Models Are Qualified Benchmark Builders: Rebuilding Pre-Training Datasets for Advancing Code Intelligence Tasks（ICPC 2025）　🏅 ACM SIGSOFT Distinguished Paper Award 🏅
    用大模型重写 CodeSearchNet 中的代码注释后，重新预训练的 CodeT5 在代码摘要、生成和翻译任务上均有提升。
  • On the evaluation of neural code summarization（ICSE 2022）　被引 189 次
    即使评测同一批代码摘要模型，BLEU 的计算方式、代码预处理和数据集划分也会影响得分与排名。

基础模型的记忆与推理

  • MemoryBank: Enhancing Large Language Models with Long-Term Memory（AAAI 2024）　被引 1,814 次
    MemoryBank 让语言模型在新对话中回忆以往的交流，并根据时间间隔和记忆的再次唤起更新记忆强度。
  • AGIEval: A Human-Centric Benchmark for Evaluating Foundation Models（Findings of NAACL 2024）　被引 982 次
    AGIEval 用中英文标准化考试题评测基础模型的知识与推理能力，题目涵盖高考、法律考试和数学竞赛。
  • Visually-Guided Policy Optimization for Multimodal Reasoning（ACL 2026）
    VGPO 在训练中提高持续关注图像线索的推理步骤和轨迹的权重，缓解多模态模型在长推理中逐渐忽略图像的问题。
