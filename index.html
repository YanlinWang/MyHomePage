Yanlin Wang 王焱林

Associate Professor and PhD Supervisor, School of Software Engineering, Sun Yat-sen University

My research on large language models, agents and trustworthy AI explores how intelligent systems can reason, remember, use tools and collaborate autonomously in settings such as software engineering, question answering and embodied interaction.

I received my bachelor's degree from Zhejiang University and my PhD in computer science from the University of Hong Kong, advised by Bruno C. d. S. Oliveira. At Microsoft Research Asia (2019–2022), my research mentors were Dongmei Zhang and Shi Han. I joined Sun Yat-sen University in 2022.

Research interests

Large Language Model Agents and Autonomous Learning

Memory, collaboration and software repair

Resolving a software issue can take several attempts. We study how agents retain useful experience, divide the work of locating and repairing a defect, and explore another repair strategy when the first one fails.

  • MemoryBank: Enhancing Large Language Models with Long-Term Memory (AAAI 2024)
  • MAGIS: LLM-Based Multi-Agent Framework for GitHub Issue Resolution (NeurIPS 2024)
  • PhoenixRepair: Rethinking Repair Strategy Exploration in Software Agents (arXiv 2026)

Repository-level code generation and retrieval

The information needed to complete a line of code may live in another file. We study how to retrieve context that matches the intended completion, when to retrieve it during generation, and how to process long code efficiently.

  • RLCoder: Reinforcement Learning for Repository-Level Code Completion (ICSE 2025)
  • AlignCoder: Aligning Retrieval with Target Intent for Repository-Level Code Completion (ASE 2025)
  • From Logical to Computational Sparsity: Structure-Aware Block-Sparse Attention for Long-Code Completion (ACL 2026)
  • Adaptive Critical Token-Aware Retrieval for Repository-Level Code Generation (arXiv 2026)

Learning from tasks and execution trajectories

Training a software agent starts with turning repository issues into tasks that can be run and checked. Once an agent has attempted them, we ask which trajectories and which individual steps are worth learning from.

  • SWE Data Construction, Automatically! (FSE 2026)
  • SWE-Prime: Fewer Trajectories, Better Performance (arXiv 2026)
Large Language Model Training, Evaluation, Trustworthiness and Safety

Code representations, training data and curricula

Source code, syntax and natural-language comments offer different signals for pretraining. In related work, we study how to rebuild code pretraining datasets and how a teacher model can introduce progressively harder problems.

  • UniXcoder: Unified Cross-Modal Pre-training for Code Representation (ACL 2022)
  • YODA: Teacher-Student Progressive Learning for Language Models (arXiv 2024)
  • Large Language Models are Qualified Benchmark Builders: Rebuilding Pre-Training Datasets for Advancing Code Intelligence Tasks (ICPC 2025)

Evaluating model capabilities and agent trajectories

Human exams, cross-file reasoning and multi-round code review place different demands on a model. We build benchmarks for these settings and investigate how execution traces can reduce the cost of evaluating agents.

  • AGIEval: A Human-Centric Benchmark for Evaluating Foundation Models (Findings of NAACL 2024)
  • RepoReasoner: Evaluating Repository-Level Code Reasoning Ability of Long-Context Language Models (FSE 2026)
  • From Static to Dynamic: Benchmarking Real-World Code Review with MCR-Bench (ISSTA 2026)
  • Efficient SWE Agent Benchmarking via Trajectory-Aware Evaluation (arXiv 2026)

Reliability and security of generated code

A patch that passes tests can still miss a review requirement, depart from project conventions or introduce a security flaw. We study how these failures and code hallucinations arise in practice and how evaluations can detect them.

  • LLM Hallucinations in Practical Code Generation: Phenomena, Mechanism, and Mitigation (ISSTA 2025)
  • Beyond Functional Correctness: Investigating Coding Style Inconsistencies in Large Language Models (FSE 2025)
  • RealSec-bench: A Benchmark for Evaluating Secure Code Generation in Real-World Repositories (Findings of ACL 2026)
  • SWE-Gate: Passing Functional Tests Is Not Enough for Software Engineering Agents (arXiv 2026)
Embodied Intelligence and AI for Science

Visual grounding and multimodal reasoning

Acting on an observation requires keeping track of its evidence during reasoning. VGPO studies how vision-language models stay grounded in an image over multiple steps. OmniGIRL tests whether software agents can use images supplied in GitHub issues.

  • Visually-Guided Policy Optimization for Multimodal Reasoning (ACL 2026)
  • OmniGIRL: A Multilingual and Multimodal Benchmark for GitHub Issue Resolution (ISSTA 2025)

Experimental feedback and autonomous decisions

How can an agent use an experimental result to revise a hypothesis and choose its next experiment? RSI-Prime starts with machine-learning experiments, identifying individual decisions within model-training runs. Extending this approach to embodied interaction and scientific experiments is an open research question for us.

  • RSI-Prime: Training Models to Train Models (arXiv 2026)
