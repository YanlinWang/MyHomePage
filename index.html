Yanlin Wang 王焱林

Associate Professor and PhD Supervisor, School of Software Engineering, Sun Yat-sen University

My research on large language models, agents and trustworthy AI explores how intelligent systems can reason, remember, use tools and collaborate autonomously in settings such as software engineering, question answering and embodied interaction.

I received my bachelor's degree from Zhejiang University and my PhD in computer science from the University of Hong Kong, advised by Bruno C. d. S. Oliveira. At Microsoft Research Asia (2019–2022), my research mentors were Dongmei Zhang and Shi Han. I joined Sun Yat-sen University in 2022.

Publications

🔥Highlight Papers

Highlight

Software agents and repository-level development

SWE Data Construction, Automatically!

FSE 2026

SWE-Factory turns GitHub issues into training and evaluation tasks by building test environments and checking that each fix makes a failing test pass.

OmniGIRL: A Multilingual and Multimodal Benchmark for GitHub Issue Resolution

ISSTA 2025

OmniGIRL tests issue resolution across four programming languages, including cases where a screenshot helps explain what went wrong.

MicroAgent: Context-Augmented Multi-agent Framework for Automatic Microservice Decomposition

ASE 2026

Five agents use code context and analysis tools to identify service boundaries and split a monolithic application into microservices.

ACM SIGSOFT Distinguished Paper Award

RLCoder: Reinforcement Learning for Repository-Level Code Completion

ICSE 2025

RLCoder learns which snippets to retrieve from other files by measuring how much they help a model predict the missing code.

Cited by 143

RepoReasoner: Evaluating Repository-Level Code Reasoning Ability of Long-Context Language Models

FSE 2026

RepoReasoner tests whether a model can trace execution across files by asking it to predict program outputs and function call chains.

HumanEvo: An Evolution-Aware Benchmark for More Realistic Evaluation of Repository-Level Code Generation

ICSE 2025

HumanEvo reconstructs the repository as it stood when a function was written to measure how later commits can inflate code-generation scores.

Reliability and efficiency of generated code

LLM Hallucinations in Practical Code Generation: Phenomena, Mechanism, and Mitigation

ISSTA 2025

This study classifies the hallucinations that arise when models generate code within a repository and tests whether retrieving relevant context reduces them.

Cited by 374

Beyond Functional Correctness: Investigating Coding Style Inconsistencies in Large Language Models

FSE 2025

A comparison of code written by developers and by language models reveals differences in readability, conciseness and robustness.

When to Stop? Towards Efficient Code Generation in LLMs with Excess Token Prevention

ISSTA 2024

CodeFast uses a lightweight classifier to recognize when a code answer is complete and stop the model from generating unnecessary tokens.

ACM SIGSOFT Distinguished Paper Award

EffiReasonTrans: RL-Optimized Reasoning for Code Translation

IEEE TSE 2026

EffiReasonTrans trains a code translation model on verified examples, then uses reinforcement learning to reward translations that pass tests with fewer reasoning tokens.

Code representation, training and evaluation

UniXcoder: Unified Cross-Modal Pre-training for Code Representation

ACL 2022

UniXcoder learns from source code, comments and abstract syntax trees in a single model that supports both code understanding and generation.

Cited by 1,511

CoCoSoDa: Effective Contrastive Learning for Code Search

ICSE 2023

CoCoSoDa masks or replaces tokens in code and queries, then uses contrastive learning to bring a query closer to its matching code.

Large Language Models Are Qualified Benchmark Builders: Rebuilding Pre-Training Datasets for Advancing Code Intelligence Tasks

ICPC 2025

Replacing CodeSearchNet comments with model-written descriptions improved a retrained CodeT5 model on code summarization, generation and translation.

ACM SIGSOFT Distinguished Paper Award

On the evaluation of neural code summarization

ICSE 2022

Choices as small as the BLEU variant, preprocessing steps or dataset split can change the scores and rankings of code summarization models.

Cited by 189

Memory and reasoning in foundation models

MemoryBank: Enhancing Large Language Models with Long-Term Memory

AAAI 2024

MemoryBank lets a language model recall earlier conversations and update its memories as time passes and topics recur.

Cited by 1,814

AGIEval: A Human-Centric Benchmark for Evaluating Foundation Models

Findings of NAACL 2024

AGIEval uses Chinese and English exams, including university entrance tests and math competitions, to probe foundation models’ knowledge and reasoning.

Cited by 982

Visually-Guided Policy Optimization for Multimodal Reasoning

ACL 2026

VGPO gives more training weight to reasoning steps and trajectories that stay grounded in the image.
